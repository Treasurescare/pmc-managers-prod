0 · How to use this manual

Every module has a fixed test-case format. Read the Precondition first — if you cannot satisfy it, either skip or arrange test data before continuing. Then follow Steps in order; do not paraphrase. Compare the actual UI against Expected UI and the network log against Expected API. Record any deviation on the tracker with the test-case ID.

Credentials live in /app/memory/test_credentials.md. Admin endpoints require both Authorization: Bearer <token> and X-CSRF-Token: <csrf_token>. The login response returns both.

Every AI-touched surface is advisory only; a failed AI call must never block a decision. If the AI proxy times out, the human path is always live.

Global error codes

CodeMeaningAction
400Bad request — payload validation failedCheck the field-level error map returned in the body.
401Missing / expired tokenLog in again. If persistent, clear cookies.
403Wrong roleCheck the require_role gate on the endpoint. Impersonate the right role.
404Entity not foundConfirm the ref/id exists.
409Conflict — envelope locked, duplicate resource, raceRefresh state; do not force-retry.
413Payload too large — DPR > 200 MBSplit and use analyze-async endpoint.
422Model validation errorCheck request schema in the OpenAPI spec.
429Rate-limitedWait per Retry-After header.
502 / 504Upstream (LLM, DocuSign, Stripe) hiccupRetry with exponential backoff. Sev-3 alert if persistent.
